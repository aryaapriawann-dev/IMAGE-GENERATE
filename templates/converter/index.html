About the Algorithms

PixelForge applies two classical image-processing algorithms entirely in Python. No neural network, no pre-trained model, and no external API is involved. Every operation is deterministic and mathematically well-defined.

Pixelation

The algorithm first computes a reduced resolution by integer division:

Wsmall = ⌊W / s⌋   Hsmall = ⌊H / s⌋

where s is the pixel block size. The image is downsampled to this smaller resolution using LANCZOS antialiasing, then upscaled back to the original dimensions W × H using nearest-neighbour interpolation. Nearest-neighbour assigns every destination pixel the value of the geometrically nearest source pixel, producing sharp, hard-edged square blocks — the visual hallmark of pixel art. Larger values of s produce fewer, larger blocks and a stronger retro effect.

Colour Quantization

A photograph may contain millions of distinct RGB values. Colour quantization partitions that colour space into k regions using the median-cut algorithm (implemented in Pillow's Image.quantize()):

  1. Find the colour channel with the greatest range.
  2. Sort all colours along that channel.
  3. Split the set at the median into two equal halves.
  4. Repeat recursively until k groups are formed.
  5. Replace every pixel's colour with its group's representative colour.

The result has at most k unique colours, giving the flat, poster-like appearance common in retro game sprites and 8-bit graphics.

Combined Pixel Art Conversion

The primary mode chains both operations in a precise sequence for optimal quality:

  1. Normalise — convert the input to RGB, handling transparent (RGBA) and grayscale images.
  2. Downsample — reduce to Wsmall × Hsmall using LANCZOS antialiasing.
  3. Quantize — apply median-cut colour quantization to the small image, limiting the palette to k colours.
  4. Upscale — enlarge back to W × H with nearest-neighbour interpolation.

Performing quantization on the downsampled image (step 3) is intentional: the smaller image contains only the colours that will actually appear in the final pixel-art blocks, so the k-colour palette represents the output faithfully. The combination of hard pixel edges and a restricted palette faithfully recreates the aesthetic of 8-bit and 16-bit era video game graphics.

All operations are performed in memory using Python and Pillow. The application contains no trained weights, no inference engine, and makes no external network requests during conversion.
